Frames is an event-driven, cloud-native social media platform built on AWS. Designed as a zero-idle-cost serverless application, it demonstrates **client-side identity federation**, **least-privilege IAM access control**, **asynchronous media processing via AWS Lambda**, and **automated continuous deployment using AWS Amplify**.

## Architecture & Data Flow

![Frames Architecture](screenshots/frames-architecture.jpg)

Frames uses a serverless architecture combining managed AWS services for authentication, storage, database operations, hosting, and event-driven processing.
